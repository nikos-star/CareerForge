# CareerForge

A modern, AI-powered platform for creating professional resumes, CVs, and cover letters. Completely free with optional coffee donations.

## Features

- 🎨 **Multiple Resume & CV Templates** - Choose from professionally designed templates
- 🤖 **AI-Powered Writing** - Get AI suggestions for content and improvements
- 📝 **Cover Letter Generator** - Create compelling cover letters with AI assistance
- 👥 **Multi-Account Types** - Support for individuals, companies, and ethical organizations
- ☕ **Optional Donations** - Free access with voluntary coffee donations
- 🔐 **Secure Authentication** - Sign up with email or social providers
- 📱 **Responsive Design** - Works on desktop, tablet, and mobile

## Tech Stack

- **Frontend:** Next.js 14 + React + TypeScript
- **Backend:** Node.js + Express (integrated with Next.js)
- **Database:** PostgreSQL + Prisma ORM
- **AI:** OpenAI API (GPT-4)
- **Authentication:** NextAuth.js
- **Payments:** Stripe (for donations)
- **Hosting:** Vercel
- **Styling:** Tailwind CSS

## Getting Started

### Prerequisites
